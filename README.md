## Languages & Core Tools

Core technologies and tools for building Android applications.

- [Kotlin](https://kotlinlang.org/) — Primary programming language for modern Android development.
- [Java](https://www.java.com/) — Legacy and still-supported language for Android.
- [Android Studio](https://developer.android.com/studio) — Official IDE for Android development.
- [Gradle](https://gradle.org/) — Build automation tool used for Android projects.
- [Kotlin Multiplatform](https://kotlinlang.org/docs/multiplatform.html) — Framework for sharing code across platforms.

## UI Frameworks

Libraries and tools for building Android user interfaces.

- [Jetpack Compose](https://developer.android.com/jetpack/compose) — Declarative UI toolkit for Android.
- [Android Views](https://developer.android.com/guide/topics/ui) — Traditional UI system for Android apps.
- [Material Design](https://m3.material.io/) — Design system for building consistent UIs.
- [ConstraintLayout](https://developer.android.com/develop/ui/views/layout/constraint-layout) — Flexible layout system for complex UI designs.
- [MotionLayout](https://developer.android.com/develop/ui/views/animations/motionlayout) — Layout for managing motion and animations.

## Architecture & Patterns

Approaches for structuring scalable and maintainable Android applications.

- MVC (Model-View-Controller) — Traditional architecture pattern.
- MVVM (Model-View-ViewModel) — Common Android architecture with ViewModel support.
- MVI (Model-View-Intent) — Unidirectional data flow architecture.
- Clean Architecture — Layered architecture for maintainability and testability.
- [Android Architecture Components](https://developer.android.com/topic/architecture) — Official libraries for lifecycle, navigation, and data handling.

## Networking

Libraries and tools for handling API communication.

- [Retrofit](https://square.github.io/retrofit/) — Type-safe HTTP client for Android.
- [OkHttp](https://square.github.io/okhttp/) — HTTP client for Android and Java.
- [Ktor](https://ktor.io/) — Kotlin-based networking framework.
- [Apollo GraphQL](https://www.apollographql.com/docs/) — GraphQL client for Android.

## Data Persistence

Tools for storing and managing local data.

- [Room](https://developer.android.com/training/data-storage/room) — Persistence library built on SQLite.
- [SQLite](https://www.sqlite.org/) — Embedded relational database engine.
- [DataStore](https://developer.android.com/topic/libraries/architecture/datastore) — Modern data storage solution replacing SharedPreferences.
- [Realm](https://github.com/realm/realm-java) — Mobile database for Android.
- [ObjectBox](https://objectbox.io/) — High-performance object database for mobile.

## Dependency Management

Tools for managing project dependencies.

- [Gradle](https://gradle.org/) — Build and dependency management system.
- [Maven Central](https://search.maven.org/) — Repository for Java and Android libraries.
- [JitPack](https://jitpack.io/) — Build system for publishing GitHub projects as dependencies.

## Testing

Frameworks and tools for ensuring code quality and reliability.

- [JUnit](https://junit.org/) — Unit testing framework for Java and Kotlin.
- [Espresso](https://developer.android.com/training/testing/espresso) — UI testing framework for Android.
- [Mockito](https://site.mockito.org/) — Mocking framework for unit tests.
- [Robolectric](https://github.com/robolectric/robolectric) — Unit testing framework that runs Android tests on the JVM.
- [UI Automator](https://developer.android.com/training/testing/ui-automator) — UI testing across apps.

## CI/CD & Distribution

Tools and platforms for building, testing, and releasing Android apps.

- [Fastlane](https://fastlane.tools/) — Automation for building and releasing Android apps.
- [Bitrise](https://www.bitrise.io/) — CI/CD platform for mobile apps.
- [GitHub Actions](https://github.com/features/actions) — Workflow automation platform.
- [Google Play Console](https://play.google.com/console/about/) — Platform for managing and distributing apps.
- [Firebase App Distribution](https://firebase.google.com/products/app-distribution) — Beta testing and app distribution.

## Performance & Debugging

Tools for profiling and optimizing app performance.

- [Android Profiler](https://developer.android.com/studio/profile) — Performance profiling tools in Android Studio.
- [LeakCanary](https://github.com/square/leakcanary) — Memory leak detection library.
- [Stetho](https://github.com/facebook/stetho) — Debugging bridge for Android apps.
- [Flipper](https://fbflipper.com/) — Debugging platform for mobile apps.

## Security

Tools and practices for securing Android applications.

- [Android Keystore](https://developer.android.com/training/articles/keystore) — Secure key storage system.
- [OWASP Mobile Security](https://owasp.org/www-project-mobile-security/) — Security guidelines and best practices.
- [SafetyNet](https://developer.android.com/training/safetynet) — API for device integrity and security checks.
- [SQLCipher](https://www.zetetic.net/sqlcipher/) — Encrypted SQLite database.
